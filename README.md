# Loom

A two-track effects chain for the NLM Xenomorpher. It also runs on standard O.R.N.8 hardware.

Patch in your voices, drums or anything else from the rack: each track takes a sound, threads it through four effects and an output stage, and moves it with modulators and a clock.
